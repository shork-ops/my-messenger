# Nexus Messenger — UI prototype

Тёмный интерфейс мессенджера с жёлтыми акцентами, созданный на React + TypeScript + Vite.

## Запуск

1. Установи Node.js LTS: https://nodejs.org/
2. Распакуй архив и открой папку `nexus-messenger` в VS Code.
3. В терминале выполни:

```bash
npm install
npm run dev
```

4. Открой адрес, который Vite покажет в терминале (обычно http://localhost:5173).

## Что работает в этом прототипе

- Переключение между чатами.
- Поиск по названиям чатов.
- Отправка сообщений в текущем чате (в памяти браузера).
- Панель друзей, профиль и каталог игр.
- Адаптивная компоновка для узких экранов.
- Жёлтая тема и тёмный интерфейс в стиле референса.

## Пока не реализовано

Это только клиентский прототип. Сообщения не синхронизируются между пользователями и пропадают после перезагрузки. Авторизация, сервер, звонки, загрузка файлов, push-уведомления и настоящие игры ещё не подключены.
