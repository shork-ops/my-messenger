### Три ошибки, которые нашли замеры, а не глаза

Это стоит выделить: каждый раз код выглядел правильным, а проверка показала обратное.

- **Значок числа непрочитанных** не появлялся, потому что архивные чаты уже были
  отфильтрованы до подсчёта. Понадобилось передать полный список отдельным свойством.
- **Обои не рисовались** дважды: сначала шаблон уходил в CSS-переменную, а оттуда в
  псевдоэлемент, где `currentColor` считается от другого элемента; потом позиция и
  размер тайла были сложены внутрь `background-image`, из-за чего браузер выбрасывал
  всё объявление целиком.
- **Камера в видеозаметке оставалась включённой** после записи: остановить дорожки
  мало, пока видеоэлемент всё ещё указывает на поток.

## Что осталось и почему

| Пункт | Почему ещё нет |
| --- | --- |
| Сквозное шифрование | Нужна другая модель хранения, а не настройка. Честно отсутствовать лучше, чем показывать замок без шифрования |
| Самоуничтожающиеся сообщения | Имеют смысл только после E2E |
| Блокировка скриншотов | Браузер не даёт такой возможности |
| Демонстрация экрана | Отдельная работа в звонках |
| Папки / фильтры чатов | Имеют смысл после архива; архив теперь есть, так что папки стали осмысленны |
| Несколько аккаунтов | Отдельная модель сессий |
| Резервная копия | Нужен экспорт истории |
| Автозагрузка медиа | Можно делать без помощи |
| Горячие клавиши и жесты | Можно делать без помощи |
| Нижняя панель вкладок | Сознательное решение: у десктопного веб-приложения боковой рельс уместнее |

## Что нужно от человека

Три вещи я сделать не могу:

1. **Подписаться на пуш на телефоне заново** — подписка сбрасывается при смене ключей.
2. **Сменить `LIVEKIT_API_SECRET`** — он был виден в выводе команды.
3. **Перевыпустить личный токен Supabase** — он тоже однажды попал в
   вывод. В документации его больше нет, но токен, показанный один раз, считается
   скомпрометированным.

Первое нужно для уведомлений, два других — гигиена. Ничто из этого не блокирует
работу приложения.
