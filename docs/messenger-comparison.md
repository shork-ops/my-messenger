## 2. Где Nexus реально силён

Эти позиции не «догонять», а держаться за них.

| Что | Почему это преимущество |
|---|---|
| **Работает в браузере и ставится как PWA** | Ни у одного из пяти конкурентов нет установки из браузера без магазина приложений. Nexus открывается по ссылке и ставится на домашний экран |
| **Поиск по @username в списке чатов** | WhatsApp и Signal ищут только по имени из контактов. У Nexus есть уникальный username — это ближе к Telegram и Discord |
| **Все тап-цели ≥ 44 px (замер: 0 мелких)** | Редкость для веб-приложения. Конкуренты приходят к этому годами |
| **Профиль всего в одном месте** | После сегодняшнего исправления. У WhatsApp профиль доступен из двух мест (настройки и в чате), что создаёт путаницу |
| **Тема оформления как настройка аккаунта** | 4 темы в одном экране |

## 4. План по приоритетам

Порядок выбран так, чтобы каждый шаг давал законченный результат, а не половину.

### Этап A — «профиль как у людей» (5 шагов)

| # | Что | Результат |
|---|---|---|
| A1 | Загрузка фото аватара (Supabase Storage) | Аватар становится настоящим |
| A2 | Поле «о себе» | В профиле есть что прочитать |
| A3 | Раздел «Профиль» отдельным пунктом в настройках | Имя, аватар, «о себе», username — в одном месте |
| A4 | Светлая тема | Пятый вариант в переключателе тем |
| A5 | Размер текста в чате (3 ступени) | Крупнее для тех, кто плохо видит |

### Этап B — «сообщения, которые можно исправить» (3 шага)

| # | Что | Результат |
|---|---|---|
| B1 | Редактирование своего сообщения | Опечатку можно исправить |
| B2 | Удаление у себя и у всех | Ошибочное сообщение не остаётся |
| B3 | Пропуск к непрочитанным | Долгая переписка листается за секунду |

### Этап C — «расширенные настройки» (6 шагов)

| # | Что | Результат |
|---|---|---|
| C1 | Уведомления: тон, звук, вибрация, тихие часы | Полноценный раздел уведомлений |
| C2 | Настройки по каждому чату (без звука, закрепить) | Гибкий контроль шума |
| C3 | Значок с числом непрочитанных | Видно, не открывая приложение |
| C4 | Архив чатов | Список остаётся чистым |
| C5 | Хранилище и сброс кеша | Понятно, сколько занимает |
| C6 | Язык интерфейса (русский / английский) | Приложение перестаёт быть только русским |

|---|---|---|

### Что сознательно не делаем

| Пункт | Почему |
|---|---|
| Сквозное шифрование | Требует смены модели хранения, а не настройки. Лучше честно отсутствовать, чем показывать замок без шифрования |
| Самоуничтожающиеся сообщения | Имеют смысл только после E2E |
| Блокировка скриншотов | Браузер не даёт такой возможности |
| Групповые звонки до 1000 | Нужен платный тариф LiveKit; текущий бесплатный даёт ~100 участник-минут в месяц |
| Папки чатов | Имеют смысл после архива; делать оба сразу — распыление |

## 5. Итог в двух числах

- **Сейчас: 35 из 72** пунктов закрыто полностью — 49% от уровня топ-мессенджеров.
- **Этапы A + B закрывают 8 пунктов**, которые пользователь замечает каждый день:
  фото аватара, «о себе», светлая тема, размер текста, редактирование, удаление,
  пропуск к непрочитанным. После них Nexus перестаёт быть «недоделанным» на ощупь.

Дальше C и D — планомерное закрытие разрыва, но они уже про удобство, а не про
ощущение сырого продукта.

## 6. Как проверялось

Замеры по Nexus: `scripts/measure-ui.mjs` и точечные проверки на живом приложении
на 390, 834, 1280 и 1440 px. Состав экранов — автоинвентаризация: рельс, кнопки
шапки чата, меню чата, меню вложений, действия с сообщением, поля настроек, разделы
приватности.

Данные о конкурентах — публично описанное поведение приложений. Где функциональность
различается по региону или тарифу, выбран вариант по умолчанию у большинства.
