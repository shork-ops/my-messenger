# Бенчмарк мессенджеров 2024–2026: эталонный набор возможностей

**Назначение документа.** Сводка фактического состояния функций у ведущих мессенджеров — как эталон (baseline) для честной оценки небольшого open-source веб-мессенджера. Документ намеренно фиксирует *отсутствие* функций и неясные места наравне с наличием: для gap-анализа «нет» так же ценно, как «есть».

**Дата среза:** 30 октября 2026 г. Все числа — из официальных страниц справки/блогов/спецификаций; где источником была не официальная страница, это указано явно (`[—]` или пометка «не проверено по первичному источнику»).

**Кого сравниваем:** Telegram, WhatsApp, Signal, Discord, iMessage / Apple Messages (включая RCS-режим), Viber, VK Мессенджер, Slack, Element / Matrix.

**Как читать таблицы.** `✅` — есть; `⚠️` — есть с оговоркой (ограничение, только платно, только на части платформ, только в определённом режиме); `❌` — нет (по официальной документации функции не существует); `❓` — официально не подтверждено / формулировки противоречивы, нужно проверить вручную в актуальном клиенте.

**Важная методологическая оговорка.** Часть вендорской документации — маркетинговая и не называет лимитов (особенно WhatsApp, Discord, Slack, VK). Для этих приложений часть чисел помечена как «не опубликовано» — это не «нет функции», а «нет официальной цифры». Slack Help Center и часть справочных статей Apple недоступны для автоматического чтения (bot-protection / JS-рендеринг), поэтому по Slack и Apple ниже приведены только те пункты, которые удалось подтвердить по доступным страницам.

### 1.2 Пояснения и подводные камни

**Telegram.**
- Редактирование и удаление — базовые, бесплатные. В конфиге MTProto есть `edit_time_limit` и `revoke_time_limit` — то есть окно редактирования/удаления серверное и может ограничиваться (типично 48 ч для всех, 2 дня для премиум; **точное значение в текущем конфиге не прочитано — проверять эмпирически**).
- Закрепление: закреплённое сообщение **приходит уведомлением всем**, даже тем, кто замьютил группу — это заявлено в FAQ.
- Самоуничтожение — критичное ограничение: таймер доступен для всех сообщений только в секретных чатах; в облачных чатах — только для медиа.
- Пересылка: у контента может стоять запрет пересылки (protected content), срок действия запроса `no_forwards_request_expire_period` = 86 400 с.

**WhatsApp.**
- Закрепление ограничено **3 сообщениями** и сроком 24 ч / 7 дней / 30 дней (официальная страница Messaging, верхний блок FAQ).
- Медиа/файлы: документы до 2 ГБ без сжатия; видео-заметки до 60 с и их **нельзя скачать** у получателя.
- Исчезающие сообщения — на весь чат, таймер общий (не «на сообщение»).

**Signal.**
- Функции за 2025–2026: **закрепление сообщений** (январь 2026), **опросы** (ноябрь 2025), опросы в личных чатах (июль 2026), **метки участников группы** (март 2026), **автоматическая проверка ключей** (август 2026), **Secure Backups** (сентябрь 2025, доработки — сентябрь 2026).
- Лимит закреплённых чатов: **10** (было 4, поднято в июне 2026) — важный маркер «щедрости» лимитов.
- Исчезающие сообщения — есть, включая режим «по умолчанию для всех новых чатов».

**Discord.**
- Нет исчезающих сообщений как пользовательской функции; есть только серверные retention-политики. Нет «удалить у всех» в привычном смысле — есть удаление сообщения (для всех в канале, если есть право).

**iMessage.**
- Отложенные сообщения — **новые** (iOS 26): Apple документирует отправку позже, редактирование времени и немедленную отправку, а также отмену при удалении до времени отправки.
- Forward — официально описан (долгое нажатие → More → выбор нескольких сообщений).
- «Удалить у всех» = Unsend (доступно ~2 минуты; **окно не указано на доступной странице — не проверено**).

**Viber.** Официально заявлены: «Delete & Edit seen messages» (редактирование и удаление для всех, **даже после прочтения**) и «Disappearing Messages».

**VK Мессенджер.** Публичной вендорской документации по лимитам/функциям не найдено — всё «❓». Функции, известные по продукту (редактирование, удаление, ответы, закреплённые сообщения, поиск), не подтверждены первичным источником в этом ресёрче.

**Slack.** Редактирование и удаление есть; «удалить у всех» ограничено правами администратора и retention-политикой.

**Element/Matrix.** Всё базовое есть на уровне спецификации: reply (`m.in_reply_to`), edit (`m.replace`), redaction, пересылка (`m.forwarded` в новых клиентах), permalink на событие. Особенность: redaction — это событие в DAG, и «физическое» удаление у получателя не гарантируется.

### 2.2 Пояснения

- **Telegram** — самый «медийно-богатый»: 2/4 ГБ файлы, безлимитное облачное хранилище, GIF-поиск на 350 млн единиц, полноценный фоторедактор, «Live Photos», встроенные документы внутри текста (август 2026).
- **WhatsApp** официально подчёркивает: голосовые заметки с транскрипцией и ускорением 1.5/2×, видео-заметки до 60 с без возможности скачать, документы до 2 ГБ, групповые звонки до 32 участников без лимита по времени, планирование звонков, «тихий» старт звонка, демонстрация экрана, поднятые руки и реакции в звонках, **звонки прямо в браузере через WhatsApp Web** (новинка, указана в шапке сайта).
- **Signal**: голосовые/видео, стикеры (шифрованные), call links. **Лимит вложений официально не публикуется** — не изобретайте цифру.
- **Discord**: файлы по тарифам — главное ограничение для «мессенджера как хранилища»; зато голосовые каналы и Go Live — сильнейшая сторона.
- **iMessage**: аудиосообщения с «Raise to Listen»; видео-кружков и исчезающих медиа нет; медиа-обмен ограничен возможностями Apple ID/Файлов.
- **Viber**: официально заявлены создание стикеров и GIF, голосовые и «instant video messages», переключение звонка между устройствами, демонстрация экрана с десктопа.
- **VK**: функции медиа-обмена по продукту есть (фото, видео, файлы, голосовые, кружки), но подтверждённых официальных лимитов в этом ресёрче нет.
- **Slack**: файлообмен как часть «file sharing»; Clips — записи аудио/видео.

### 5.2 Пояснения и «честные» оговорки

- **Telegram — самый частый источник ошибок в gap-анализе.** E2EE только в Secret Chats (1:1) и в новых E2EE-групповых звонках (до 200 участников, верификация 4 эмодзи, блокчейн-состояние звонка). Облачные чаты, группы, каналы — **не E2EE**. Это осознанный trade-off ради мультиустройственности и поиска.
- **WhatsApp**: E2EE по умолчанию для сообщений/звонков/медиа, плюс E2EE-бэкапы, Chat Lock, «Silence unknown callers», скрытие last seen/online.
- **Signal**: E2EE для всего и всегда; **PQXDH** и **SPQR** (пост-квантовый ratchet, октябрь 2025) — уникальная криптографическая позиция; автоматическая проверка ключей (2026); Secure Backups (E2EE, опционально); прокси/цензуроустойчивость.
- **Discord**: важное уточнение 2026 — **все голосовые и видеозвонки E2EE по умолчанию** (протокол DAVE, open-source, аудит Trail of Bits), кроме stage-каналов. Но текстовые сообщения — не E2EE.
- **iMessage**: E2EE для iMessage; **«Encrypted» индикатор** в шапке чата; RCS — с read receipts, typing indicators, Tapback, inline replies и HD-медиа, но E2EE — только при поддержке операторами. Есть Contact Key Verification.
- **Viber**: E2EE по умолчанию, ключи только на устройствах, trusted contacts, disappearing messages с уведомлением о скриншоте, hide chats под PIN, hidden-number chats.
- **VK**: подтверждено только про E2EE в звонках (сквозное шифрование с 2018 г.); про E2EE сообщений — требуется проверка.
- **Slack**: E2EE нет, но есть Enterprise Key Management, DLP, retention, SSO/SAML — корпоративная модель «доверия админу».
- **Element/Matrix**: E2EE по умолчанию, cross-signing, верификация устройств, MSC4147 (подпись ключей устройств внутри Olm-сообщений) — защита от подмены устройства.

### 6.2 Пояснения

- **Лимиты пинов — важный маркер**: Telegram 5/10, Signal 10, WhatsApp — очень мало (3 сообщения в чате). Для «маленького мессенджера» лимит пинов — дешёвая победа.
- **Папки чатов**: Telegram — самая гибкая система (до 30 папок в Premium), WhatsApp — Inbox filters (All/Unread/Favorites/Groups), Discord — server folders, VK — папки в веб-версии.
- **Отчёты о прочтении**: Apple документирует отдельную страницу «Turn read receipts on or off» — наличие переключателя подтверждено; WhatsApp и Signal тоже позволяют отключить.
- **Мультиаккаунт**: Signal — единственный, у кого нет нескольких аккаунтов на одном устройстве (зато много linked-устройств: Android-телефон/планшет/iPhone с августа 2026).
- **Веб-клиент**: у Signal нет веб-версии — принципиально (приватность/архитектура). Для веб-мессенджера это важный ориентир: «веб-версия» — не само собой разумеющаяся функция.
- **Перевод/транскрипция**: WhatsApp — перевод встроен, транскрипция голосовых встроена; Telegram — перевод (Premium) и транскрипция (Premium); Apple — системный перевод/транскрипция; Signal и Discord — нет.

**Три вывода, важных для gap-анализа:**
1. **Telegram — единственный «облачный» мессенджер с поистине безлимитной историей и синхронизацией на N устройств**; плата за это — отсутствие E2EE в облачных чатах.

3. **Ни один массовый мессенджер не совмещает «облако + E2EE» идеально**; WhatsApp/Signal/`Element` решают это через E2EE-бэкапы ключами пользователя.

- **MatrixRTC (MSC4143) смержен в main 21 октября 2026** — реальное время (звонки) как часть протокола, с явным блоком `encryption` и E2EE на уровне комнаты и приложения; Element Call на этой основе.
- Направления 2026: матрикс RTC (MSC4195 LiveKit, MSC4196 `m.call`), удалённое управление устройствами (MSC4190), упрощённый sliding sync (MSC4186), профили с часовым поясом (MSC4175), E2EE-вложения (гайд), device keys в Olm (MSC4147).

## 10. Чек-лист достоверности: что можно цитировать, а что нельзя

Чтобы документ не «поплыл» при использовании, утверждения разделены на три уровня.

### Уровень A — подтверждено официальной страницей вендора в этом ресёрче
- **Telegram:** 200 000 в группе; каналы без лимита подписчиков; 2 ГБ / 4 ГБ файлы; 4 096 знаков (базовый лимит) и >32 000 с Rich Text Editor; E2EE-групповой звонок до 200; `groupcall_video_participants_max` = 1000; 11 уникальных реакций; 5/10 пинов чатов; 10/30 папок; passkeys; Communities; welcome messages; ephemeral messages in groups; 350 млн GIF.
- **WhatsApp:** файлы 2 ГБ; закрепление до 3 сообщений со сроками 24 ч / 7 дн / 30 дн; видеосообщения 60 с без скачивания; голосовые 1.5×/2× + транскрипция; групповые звонки до 32 без лимита времени; планирование звонков; поднятые руки и реакции; шаринг экрана; звонки в вебе; E2EE по умолчанию; E2EE-бэкапы; Chat Lock; Channels; channel subscriptions «не для всех».
- **Signal:** Secure Backups (E2EE, 100 ГБ на платном, бесплатно — 45 дней медиа); pins 4→10; polls (ноя 2025) и polls в 1:1 (июль 2026); member labels; автоматическая проверка ключей; linked devices (Android-планшет/телефон/iPhone); Screen security против Recall; PQXDH/SPQR; usernames; call links; **веб-версии нет**.
- **Discord:** **все голосовые/видеозвонки E2EE (DAVE)** с марта 2026, кроме stage; private profiles; spoiler channels; `@game` (desktop); Meta Quest; Frames; Nitro-темы; Electron 42.
- **Apple:** отложенные сообщения; Unsend/Edit; Forward; Polls; форматирование и эффекты (полный список); Invisible Ink; RCS-характеристики; read receipts on/off; Messages via satellite; Group FaceTime; Communication Safety.
- **Viber:** Communities без лимита участников; «Delete & Edit seen messages»; Disappearing Messages с уведомлением о скриншоте; hide chats под PIN; hidden-number chats; E2EE по умолчанию; Viber Out; демонстрация экрана с десктопа.
- **Matrix:** E2EE по умолчанию; MSC4143 смержен 21.10.2026; MSC4147.

### Уровень B — распространённое значение, но в этом ресёрче НЕ подтверждено официальной страницей (в таблицах помечено ❓)
- Лимит группы WhatsApp (1 024), Signal (1 000), Group FaceTime (32), iMessage-группа (32–50).
- Лимиты Discord по файлам (10/50/500 МБ) и длине сообщения (2 000 знаков).
- Лимит Slack по файлам (1 ГБ Free) и длине сообщения (~4 000).
- Альбомы Telegram (10) и WhatsApp (30).
- Окна Unsend/Edit в iMessage (~2 мин / 15 мин).
- Лимит участников групп VK, размеры файлов VK, E2EE сообщений VK.
- «Один аккаунт на устройство» у Signal (архитектурно следует из модели linked-устройств, но официальной формулировки в этом ресёрче нет).

### Уровень C — функций НЕТ по официальной документации (в таблицах ❌)
- **Signal:** каналы/broadcast, боты, веб-клиент, папки чатов, перевод сообщений, транскрипция, реклама/спонсорство, несколько аккаунтов на одном устройстве.
- **Discord:** исчезающие сообщения как пользовательская функция, view-once медиа, «кружки», read receipts в стиле мессенджеров, E2EE текстовых сообщений.
- **Telegram:** E2EE облачных чатов/групп/каналов; self-destruct для *всех* сообщений в облачных чатах; безлимитные пины чатов (лимит 5/10).
- **WhatsApp:** отложенные сообщения, каналы с ролями как в группе, секретные чаты, произвольные кастомные emoji-реакции.
- **iMessage:** каналы, роли, секретные чаты, исчезающие сообщения, «last seen», мультиаккаунт, боты.
- **Slack:** E2EE, «удалить у всех» без прав администратора, «кружки», стикер-платформа.
- **Element/Matrix:** «кружки»; бот-платформа в смысле Telegram (есть App Services, но экосистема иная).

## 11. Практические выводы для gap-анализа веб-мессенджера

1. **Базовая гигиена, без которой «не мессенджер»** (есть у всех девяти): текст, reply, forward, edit, delete, pin, in-chat search, глобальный поиск, реакции, файлы, голосовые, звонки 1:1, тёмная тема, unread-счётчики, typing, включение/выключение read receipts, блокировка пользователя, удаление аккаунта.
2. **«Средний класс» — есть у 7+ из 9**: групповые звонки, исчезающие сообщения, папки/архив, мьют с расписанием, мультиаккаунт, QR/username-обнаружение, E2EE (у 5 из 9 по умолчанию для текста), самоуничтожение медиа, транскрипция голосовых.
3. **Дифференциаторы уровня Telegram/iMessage**: эффекты сообщений (iMessage), отложенные сообщения (только Telegram и новейший iOS), форумы/топики (Telegram, Discord, Slack), каналы-вещание (Telegram, WhatsApp, Discord, Slack, Matrix), форматирование code block + spoiler (Telegram, Discord, iMessage «invisible ink»).
4. **Чего нет почти ни у кого** (потенциальная «дешёвая» дифференциация для open-source проекта): веб-клиент с E2EE у Signal (нет вообще), E2EE в текстовых чатах Discord (нет), E2EE в облачных чатах Telegram (нет), «удалить у всех» без ограничений у Slack (нет), папки чатов у Signal (нет).
5. **Честное место для «небольшого open-source веб-мессенджера»**: преимущество — веб-first и открытость (Matrix/Element — единственный прямой конкурент с открытой спецификацией и веб-клиентом); слабость — масштаб сообществ, боты, платежи, звонки уровня Telegram/Discord.
